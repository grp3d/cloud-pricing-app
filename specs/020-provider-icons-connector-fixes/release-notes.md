# Release notes: v0.0.3

Feature 020: fixes from the v0.0.2 release. Price Change now reacts to every pricing edit, and
GCP and Azure diagrams show their own icons.

## What's fixed

- **Price Change follows every edit.** Before, changing a GCP machine's vCPUs or memory, an Azure
  VM's operating system, or the region a service is priced in changed the total but not Price
  Change, which kept showing the previous value. The "Architecture has been updated since last
  pricing" notice missed the same edits. Both now compare everything a price depends on. An
  edit that's put back to its old value still counts as no change.
- **Price Change after a Duration switch uses the real settings.** When the Duration changes, the
  previous contents are priced again at the new Duration. That re-pricing now uses the
  architecture's provider, each service's region and its GCP or Azure options. Before, it
  priced everything as AWS in us-east-1, so GCP and Azure comparisons were wrong.
- **GCP and Azure icons.** GCP and Azure diagrams showed AWS icons. Now:
  - Each service shows its own provider's icon, for example Compute Engine, Cloud SQL, Virtual
    Machines or SQL Database.
  - Parts of a large service that have their own icon show it, for example Persistent Disk and
    external IP addresses in Compute Engine, Cloud NAT and Cloud Load Balancing in Networking,
    Azure managed disks (Disks), public IP addresses, file shares and queues.
  - A service with no icon of its own, which includes most GCP marketplace products, shows a
    tile with the provider's logo and the service's name, cut to three lines. Hovering shows the
    full name.
  - Every GCP and Azure service in the compute, storage, database and networking categories has
    an icon.
  - Icon positions and sizes are unchanged, so existing layouts look the same apart from the
    icons. The pop-out diagram shows the same icons.

## Changes to existing behaviour

- **One AWS change: Price Change after a Duration switch with boxes outside us-east-1.** The
  previous contents used to be re-priced at us-east-1 rates whatever their region. They're now
  re-priced in their own regions, so the value can differ from v0.0.2. **The new value is the
  correct one.** Every other AWS result, and every AWS icon, is unchanged.
- **Last calculations stored before this update.** A last calculation stored in the browser by
  v0.0.2 has no regions or options.
  - Calculating again with the same Duration works as before.
  - After a Duration switch, an AWS architecture is re-priced as in v0.0.2.
  - After a Duration switch, a GCP or Azure architecture shows no Price Change value, with the
    note "Not available: previous calculation from prior version is unreliable".
  - The next calculation stores a complete record, so Price Change is exact from then on.
- **API additions** (both optional, so older clients keep working):
  - `POST /catalog/calculate-snapshot` takes `provider`, plus `region` and `provider_options` on
    each selection.
  - SKU selections return `service_name`. It is null for AWS.

## Icons

- The GCP and Azure icons come from Google's and Microsoft's official architecture icon sets.
  They're shipped unmodified, and only the ones in use. Each icon folder has a README with the
  source and terms.
- The icon maps are generated by `backend/scripts/generate_provider_service_icon_map.py
  --provider gcp|azure` from the newest pricing snapshot, plus a reviewed list of matches. Its
  report lists any categorized service that's missing an icon. Re-run it after a big change to
  the price lists. The AWS icon script is unchanged.

## Upgrading

- No database migration and no new settings.
- GCP and Azure stay disabled in production until the pricing pipeline's GCP and Azure rollout,
  as in v0.0.2.

## Not in this release

- **Connectors are unchanged.** Connecting individual services, adding connectors from the
  canvas, and branching connectors are deferred until after the planned UI overhaul (see the
  spec's "Deferred: Connector Updates" section).
