# Design brief and inputs

These files are inputs to the app's design. They are kept as a record and are not updated to
match the app. For how the app works today, see the other pages in [`docs/`](../); for what
each feature built, see its `specs/0NN-*/spec.md`.

- `functionality.md`: the original design brief (September 2026). It still lists ideas not yet
  built.
- `functionality_YYYY-MM-DD*.md`: later change requests, each the input to one feature spec.
- `common_aws_architectures.md`: the source for the four standard architectures (JSON). The
  resolver script reads it; see [development.md](../development.md#standard-architectures).

New change requests go here too. Specs written before 2026-11-10 refer to these files at their
old place, `docs/` instead of `docs/brief/`.
